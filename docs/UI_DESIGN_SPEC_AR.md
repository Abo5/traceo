# Traceo — مواصفة التصميم والواجهات (UI Specification)

**الإصدار 2.0 · نظام التصميم Forge · عربي أولاً RTL · داكن فقط**

هذه الوثيقة هي المرجع الكامل لكل ما يخص واجهة المستخدم في Traceo: الفلسفة، الرموز (Tokens)، المكونات، وتفاصيل كل شاشة من الشاشات الـ 16. أي شاشة أو مكوّن جديد يجب أن يلتزم بها حرفياً.

---

## 1. فلسفة التصميم

Traceo أداة هندسية موجهة لفرق الجودة (QA) في السوق السعودي — التصميم يوازن بين:

1. **مصداقية هندسية** — بأسلوب أدوات المطورين الحديثة (Linear / Vercel) لكن **دافئ وملوّن** بدل الأزرق الرمادي المعتاد: قماش داكن بارد بلمسة بنفسجية، ولون قائد كهرماني حار.
2. **العربية أولاً** — ليست ترجمة فوق تخطيط إنجليزي؛ كل شاشة مصممة RTL منذ البداية، والإنجليزية هي الانعكاس.
3. **البيانات بطابع Mono** — أي معرّف أو رقم أو مسار أو كود يظهر بخط JetBrains Mono باتجاه LTR دائماً، حتى داخل الجُمل العربية. هذا ما يمنح الصفحات "نسيج المصداقية الهندسية".
4. **العمق بالحدود لا بالظلال** — لا توجد ظلال إطلاقاً في الصفحات؛ الفصل بين الطبقات يتم بحدود 1px + تدرّج درجات السطح (Surface Steps).
5. **الحركة هادئة وسريعة ومقصودة** — لا شيء يرتد (Nothing bounces). مدد 120–320ms فقط.

### 2.9 الأبعاد والزوايا والحركة

- **شبكة 4px**: مقاسات الفراغات 0/2/4/6/8/12/16/20/24/32/40/48/64
- **الزوايا**: 6px (رقاقات/شارات) · 8px (أزرار/حقول) · 10px (كتل كود، صفوف) · 12px (بطاقات) · 14–16px (بطاقات كبيرة/حاويات جداول) · 22px (Modal) · 999px (Pill)
- **الظلال: لا شيء.** (استثناء وحيد: طبقة الـ Modal فوق `--overlay`)
- **الحركة**: `--dur-fast:120ms` (معظم الانتقالات) · `--dur-base:200ms` · `--dur-slow:320ms` · Easing `cubic-bezier(.2,.6,.2,1)` · **ضغط الأزرار scale(0.97)**
- مقاسات لمس: حقول 44px، أزرار 44px (sm: 34px)، الهيدر 64px

## 3. قواعد RTL والاتجاهات (Bidi) — إلزامية

هذه القواعد وُلدت من مراجعة بصرية فعلية وأصلحت أخطاء حقيقية:

1. `<html dir>` يتبدل ديناميكياً (ar=rtl افتراضياً، en=ltr) عبر مزوّد اللغة؛ اللغة محفوظة في localStorage.
2. **كل** معرّف/مسار/رقم/JSON يُغلّف بـ `dir="ltr"` + خط Mono — مكوّن `Mono` يفعل ذلك تلقائياً.
3. النصوص التي قد تكون بأي لغة (أوصاف المتطلبات، عناوين الحالات) تأخذ `dir="auto"` — وإلا انقلبت النقطة الختامية للنص الإنجليزي إلى أوله داخل RTL.
4. الاقتطاع (Ellipsis) للعناوين الإنجليزية داخل قوائم RTL: العنوان داخل span بـ `dir="auto"` + `overflow:hidden; text-overflow:ellipsis; white-space:nowrap` — وإلا أكل الاقتطاع بداية الجملة بدل نهايتها.
5. **التواريخ والأوقات**: تُنسّق `YYYY-MM-DD HH:mm` وتُعرض عبر `DateTimeText` (mono + ltr) — وإلا تبعثرت الأرقام (اليوم ينفصل لأقصى الطرف).
6. مسارات API داخل جمل عربية: `nowrap` + ltr حتى لا تنكسر الشرطة المائلة عند التفاف السطر.
7. الخصائص المنطقية في CSS دائماً: `margin-inline` / `padding-inline` / `inset-inline` — لا left/right صريحة.
8. الشريط الجانبي يمين في العربية، يسار في الإنجليزية — تلقائي عبر اتجاه المستند.

## 4. هيكل التطبيق (App Shell)

### 4.1 الهيدر العلوي (ثابت، 64px، كل الشاشات)
- خلفية `rgba(19,18,23,.86)` + `backdrop-filter: blur(12px)` + حد سفلي 1px
- **البداية**: مربع الشعار 30×30 (زوايا 9px، خلفية `--grad-hero`، حرف "T" داكن 700) + كلمة **Traceo** (17px/700/-0.02em) + الشعار الفرعي mono ‏`requirement → test → result` (11px muted، ltr)
- **النهاية**: مبدّل اللغة (Pill مقسّم AR/EN — النشط بخلفية `--accent-fill` ونص `--accent-fg`) + اسم المستخدم + زر تسجيل الخروج (ghost)

### 4.2 الشريط الجانبي (صفحات المشروع، ~240px)
- خلفية `--surface`، حد 1px جهة المحتوى
- أعلى: اسم المشروع + شارة اللغة (ar/en) + شارة "مؤرشف" عند اللزوم
- **التجميع بعناوين Eyebrow** (10.5px uppercase muted):
  - **مساحة العمل**: نظرة عامة، المتطلبات، الواجهات
  - **التحليل**: التوليد، المراجعة، التشغيلات، المصفوفة
  - **الإعداد**: البيئات
- عنصر القائمة: 13px، padding ‏10px 12px، زوايا 8px؛ **النشط**: خلفية `--accent-subtle` + نص `--accent`؛ hover: `--surface-2`

### 4.3 بنية الصفحة القياسية
```
PageHeader (عنوان 700 + سطر شارح ثانوي + إجراءات يمين/شارة FR)
  ↓ فراغ 16-20px
بطاقات/شبكات المحتوى (gap 16px)
```

### أنماط متكررة (Patterns)
- **رقاقة مرقّمة ملوّنة**: مربع 26px زوايا 8، خلفية `rgba(spectrum,.16)` + رقم mono باللون — لخطوات خط الأنابيب والأقسام
- **شارة HTTP Method**: mono uppercase — GET أزرق، POST أخضر، PUT/PATCH أصفر، DELETE أحمر
- **كتلة كود/أدلة**: خلفية `--bg`، حد 1px، زوايا 10، mono 12px، سطر 1.7، `dir="ltr"`، `pre-wrap`
- **منطقة سحب وإفلات**: حد متقطع 1.5px `--border-strong`، زوايا 12؛ hover/drag → حد `--accent`
- **بطاقة مميزة (Highlight)**: حد `--accent` + خلفية `rgba(255,138,34,.06)`
- **لوحة تنبيه كهرمانية**: خلفية `--accent-subtle` + نص شارح — تُستخدم لرسالة "التوليد مقيّد بالواجهات المكتشفة"

## 6. خريطة ألوان الحالات (إلزامية وموحّدة)

| الحالة | اللون |
|---|---|
| مسودة draft / مؤرشف archived / ملغى cancelled | muted |
| معتمد approved / مؤكد confirmed / ناجح passed / مكتمل completed | success |
| مرفوض rejected / فاشل failed / مُجهض aborted | error |
| قديم stale / خطأ errored / متغيّر changed | warning |
| مستخرج extracted / في الانتظار queued / قيد التنفيذ running | info |
| محذوف removed | error |

حالة تغطية المتطلب في المصفوفة: `not_covered`=warning · `covered_not_run`=info · `passing`=success · `failing`=error · `errored`=warning

## 7. الشاشات — تفصيل شاشة بشاشة

### 7.1 تسجيل الدخول `/login` والتسجيل `/register`
- بطاقة واحدة ~400px وسط قماش `--bg`؛ الشعار أعلاها
- حقول عربية التسمية (البريد الإلكتروني/كلمة المرور) مع `autocomplete` صحيح
- **صندوق تلميح الديمو** (mono، على `--surface-2`): ‏`demo@traceo.sa / Demo1234!`
- زر أساسي كهرماني بعرض كامل؛ رابط تبديل دخول/تسجيل ghost

### 7.2 قائمة المشاريع `/projects`
- شبكة بطاقات (280px+): اسم المشروع 600، شارة لغة، تاريخ الإنشاء muted، معرّف مختصر mono
- زر "مشروع جديد" primary → Modal (اسم + لغة ar/en)
- أرشفة/حذف عبر Modal تأكيد (الحذف زر danger)

### 7.3 لوحة القيادة (نظرة عامة) — تركيبة v2
1. **صف 5 مؤشرات KPI**: التغطية % (كهرماني + RefChip FR-050) · الحالات المعتمدة (أخضر) · آخر تشغيل `#1001` بصيغة `207/265` (أزرق) · عيوب مفتوحة مع عدد الحرجة (أحمر عند وجود حرجة + FR-052) · وسيط مدة التشغيل بالثواني (سماوي)
2. **شبكة 1.6/1**: بطاقة **اتجاه التغطية** (FR-054) برسم TrendBars عبر آخر 14 تشغيلاً + بطاقة **آخر تشغيل** بدونات النتائج + الأعداد الملوّنة + زر "فتح التقرير"
3. **صف مزدوج**: بطاقة **مراقبة الانحدار** (FR-062) — قائمة حالات كانت تنجح وفشلت الآن: SeverityBadge + عنوان مقتطع dir-auto + رقاقات REQ + شارة النتيجة تربط للتشغيل؛ الحالة الفارغة خضراء "لا انحدارات — كل ما نجح سابقاً ما زال ينجح" · بطاقة **فجوات التغطية** (FR-051) — بطاقات بصبغة تحذيرية: معرّف REQ ‏mono أصفر + سبب الفجوة + سطر **الإجراء التالي** muted + زر "توليد مستهدف"
4. رقاقات حالات الاختبار الخمس (StatusDot + التسمية + العدد mono)
5. **شريط خط الأنابيب**: 5 خطوات برقاقات مرقّمة بألوان الطيف: تحليل المتطلبات ← اكتشاف الواجهات ← التوليد المقيّد ← المراجعة البشرية ← التنفيذ والتتبّع
6. إجراءات سريعة (أزرار ثانوية + "تشغيل جديد" primary)

### 7.4 المتطلبات
- **منطقة رفع** بحد متقطع (PDF/DOCX/MD حتى 50MB) → عند الرفع شريط تقدم + رسالة حالة المهمة
- قائمة المستندات: اسم الملف + شارة إصدار (v1، v2…) + شارة حالة التحليل
- **جدول المتطلبات**: معرّف REQ ‏mono كهرماني · الوصف `dir="auto"` · شريط الثقة (Progress صغير — أقل ثقة يُرتّب أولاً في طابور التأكيد) · شارات النوع/الأولوية/الحالة · زر اعتماد لكل صف + زر "اعتماد الكل"
- تحرير عبر Modal (وصف/معايير قبول/نوع/أولوية)؛ فلاتر (حالة/نوع/بحث)

### 7.5 الواجهات (Endpoints)
- بطاقة استيراد بتبويبين Pill: رابط URL / رفع ملف؛ عرض التحذيرات وdiff بعد الاستيراد
- **جدول الجرد** (RefChip FR-024 في الرأس): شارة Method ملوّنة · المسار mono ltr · الملخص · عدد المعاملات · **الاختبارات** (mono — أصفر إذا 0) · **التغطية** (Progress ‏52px + نسبة: أخضر ≥80، أصفر ≥40، أحمر أقل) · **آخر نتيجة** (StatusDot + التسمية) · شارة الأمان (محمي/مفتوح) · مفتاح تضمين/استبعاد
- **صفوف بلا اختبارات**: خلفية صفراء خافتة `rgba(255,197,61,.07)`

### 7.6 التوليد
- **يمين (RTL)**: قائمة اختيار المتطلبات المؤكدة (checkbox + معرّف mono + وصف dir-auto)، اختيار الكل/حسب الأولوية؛ تدعم `?req=` للتوليد المستهدف
- محدد **العمق** بثلاث Pills مع سطر تلميح لكل خيار: smoke / standard / exhaustive
- **يسار**: بطاقة ملخص لاصقة (sticky): عدد المختار، عدد الواجهات، و**اللوحة الكهرمانية**: "التوليد مقيّد بالواجهات المكتشفة فقط — أي حالة تشير إلى واجهة غير موجودة تُستبعد قبل الحفظ"
- زر توليد primary → شريط تقدم حي + رسالة المرحلة
- **لوحة النتيجة**: بطاقتا إحصاء (توليد أخضر / استبعاد بصبغة خطأ) + قائمة المتعذّر ربطه (mono + سبب) + زر CTA "إلى المراجعة"

### 7.7 المراجعة — الشاشة الرائدة
تخطيط بلوحين:
- **لوح القائمة**: فلاتر Pill (الكل/مسودة/معتمد/مرفوض/قديم) + بحث + قائمة الحالات: checkbox جماعي، عنوان مقتطع dir-auto، شارة التقنية (EP/BVA/سلبي/جداول قرار/تعريب/يدوي)، StatusDot، رقاقات REQ؛ **المحدد** بحد كهرماني
- **لوح التفاصيل**:
  - **لوحة المتطلب المرتبط** بحد كهرماني: معرّفه mono + نصه الكامل (جوهر الشاشة: النص بجانب الحالة — FR-REV-02)
  - سطر تعريف mono: التقنية · الأولوية · النموذج · إصدار الـ Prompt (+ RefChips ‏FR-035/FR-036 في الترويسة)
  - **الخطوات**: لكل خطوة `METHOD /path` ‏mono + كتلة طلب JSON غائرة (على `--bg`، ltr) + قائمة التحققات (رقاقات op: eq/gt/contains…) + الاستخراجات
  - أزرار: **اعتماد** primary · **رفض** danger (Modal: سبب من قائمة incorrect/shallow/duplicate/other + نص حر) · **تعديل** (Modal بحقول + محرري JSON مع تحقق قبل الحفظ)
- **اختصارات لوحة المفاتيح**: `a` اعتماد · `r` رفض · `j/k` تنقّل — معطلة أثناء التركيز في حقل؛ بعد الإجراء تنتقل التحديدة تلقائياً للحالة التالية **دون فقدان الفلاتر**
- شريط جماعي عند تحديد عدة حالات: اعتماد الكل / رفض الكل

### 7.8 التشغيلات
- **بطاقة الإطلاق**: اختيار البيئة + عدّاد "265 حالة معتمدة جاهزة للتشغيل" (الرقم mono أخضر 700) + خيار مجموعة فرعية (Modal متعدد الاختيار) + زر تشغيل primary
- **لوحة التشغيل الحي** (تحديث كل 1.5 ثانية): شارة الحالة + رقاقات العدادات تتصاعد + زر إلغاء + رابط التقرير عند الاكتمال
- **جدول السجل**: `#10xx` mono · شارة الحالة · النتائج الملوّنة · البداية/النهاية عبر `DateTimeText` · المشغّل

### 7.9 تقرير التشغيل
- ترويسة: `تشغيل #1001` + شارة الحالة + بيئة وتواريخ mono + زر تصدير HTML
- **5 بطاقات KPI**: الكل / ناجح (أخضر) / فاشل (أحمر) / خطأ (أصفر) / المدة
- تبويبات Pill: **الإخفاقات** / جميع النتائج / مقارنة
- تبويب الإخفاقات: **Pills فلترة الشدة** (الكل/حرج/كبير/طفيف بأعدادها) + بطاقات عيوب أكورديون: معرّف الحالة mono أحمر + العنوان + رقاقات REQ + **SeverityBadge**؛ المفتوحة تعرض: خطوات إعادة الإنتاج مرقّمة، كتلتي الطلب/الاستجابة الغائرتين (ltr، الأسرار مموّهة ••••)، رقاقتي **المتوقع/الفعلي** (subtle أخضر/أحمر)
- **قسم الأداء** (RefChip FR-044): جدول لكل واجهة: Method+Path ‏mono · P50 · P95 · MAX · عدد النداءات
- تبويب المقارنة: اختيار تشغيل آخر → رقاقة **فرق التغطية** (+/- نقاط بصبغة نجاح/خطأ) + قوائم "أصبح يفشل" (أحمر) و"أصبح ينجح" (أخضر) + عدد غير المتغير

### 7.10 المصفوفة (RefChip FR-050)
- أعلى: StatCard التغطية % + StatCard الفجوات + Pills فلترة بالحالة
- **صفوف الشبكة**: معرّف REQ ‏mono كهرماني · الوصف `dir="auto"` مقتطع · رقاقات الحالات المرتبطة (StatusDot لكل حالة، تربط للمراجعة) · Pill حالة التغطية · Progress ناجح/إجمالي بالتدرج الدافئ
- **قسم الفجوات**: بطاقات بحد أصفر وخلفية تحذيرية: معرّف mono أصفر + السبب بالعربية (لا توجد واجهة مطابقة / لا حالات معتمدة…) + **سطر الإجراء التالي** muted + زر "توليد مستهدف"؛ الحالة الفارغة: "✓ لا توجد فجوات — كل المتطلبات المؤكّدة مغطاة"
- زر تصدير Excel في الترويسة

### 7.11 البيئات
- بطاقات البيئة: الاسم + `base_url` ‏mono ltr + شارة نوع المصادقة + شارة TLS + **شارة "سر محفوظ" ••••** (الأسرار كتابة فقط — لا تُعرض أبداً بعد الحفظ)
- Modal إنشاء/تعديل: نوع المصادقة يبدّل الحقول الشرطية (api_key/basic/bearer/oauth2)؛ ترك حقل السر فارغاً عند التعديل = الإبقاء على المحفوظ
- زر **فحص الاتصال** → شارة نتيجة inline (متصل + كود الحالة / غير متصل + الخطأ منقّحاً)

### 7.12 الأعضاء والتدقيق `/settings/*`
- الأعضاء: جدول (اسم/بريد/دور بقائمة تحرير مباشرة/إزالة) + Modal دعوة
- التدقيق: جدول زمني تنازلي: الوقت DateTimeText · الفاعل · الفعل mono (`test_case.approved`) · الكائن · تفاصيل قابلة للتوسيع؛ ترقيم صفحات بمؤشر (Cursor)

### 7.13 تقرير HTML المصدَّر (خارج التطبيق — للتسليم)
مستند مستقل بنفس الهوية (داكن + كهرماني + mono) يبنيه الخادم: `dir="rtl" lang="ar"` عند مشروع عربي؛ ترويسة `#1001` + صف KPI + الإخفاقات كتقارير عيوب كاملة الأدلة + الجدول الكامل؛ **وضع طباعة** `@media print` بخلفية بيضاء — هو مسار تسليم الـ PDF للعميل. وملف Excel بأربع أوراق برأس معبأ `#FF8A22` نص أبيض + `rightToLeft` لكل الأوراق عربياً.

## 8. حالات الواجهة الإلزامية (لكل شاشة)

| الحالة | الشكل |
|---|---|
| تحميل | نص "جارٍ التحميل…" muted أو شريط تقدم للمهام الطويلة — **لا شاشة بيضاء أبداً** |
| فارغ | مكوّن Empty بعنوان + **تلميح الخطوة التالية** ("ارفع مستند المتطلبات للبدء") |
| خطأ | نص الخطأ بلون `--error` + زر "إعادة المحاولة" — لا Stack traces أبداً |
| مهمة خلفية | شريط تقدم + رسالة المرحلة الحالية، مع polling كل ~1s |
| تشغيل حي | عدادات تتحدث كل 1.5s + زر إلغاء |

## 9. الوصولية (Accessibility)

- تباين AA: نص `--accent-fg` الداكن فوق الكهرماني (لا أبيض فوق كهرماني)؛ النص الثانوي ≥ 4.5:1 على الأسطح
- تركيز مرئي دائماً: حلقة `--accent-ring` بسماكة 2–3px
- المراجعة قابلة للتشغيل الكامل بلوحة المفاتيح (a/r/j/k)
- الدلالة لا تعتمد على اللون وحده: كل شارة تحمل نصاً، وكل StatusDot يجاوره تسمية
- `autocomplete` صحيح على حقول الدخول؛ الأزرار المعطلة `opacity` مخفّضة + `cursor: not-allowed`

## 10. ما لا يُسمح به (Anti-patterns)

1. ❌ ظلال (box-shadow) على أي بطاقة أو زر
2. ❌ نص أبيض فوق الكهرماني — دائماً `--accent-fg` الداكن
3. ❌ معرّف أو رقم أو مسار بخط الواجهة أو باتجاه RTL
4. ❌ تاريخ يُعرض دون `DateTimeText`
5. ❌ استخدام ألوان الطيف كخلفيات واسعة — رقاقات وأرقام فقط
6. ❌ أكثر من زر primary واحد في المشهد الواحد
7. ❌ `left/right` صريحة في CSS بدل الخصائص المنطقية
8. ❌ قائمة بلا حالة فارغة، أو خطأ بلا زر إعادة محاولة
9. ❌ حركة أطول من 320ms أو بارتداد (bounce/spring)
10. ❌ عرض سر بيئة بعد حفظه — كتابة فقط + مؤشر مموّه
